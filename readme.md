# f-22 raptor pcb keychain

this is a cool looking pcb keychain ,

made in kicad using a ldr module 

that can glow in the darkness .

and also this is my second pcb project .

# About 

this is a keychain pcb , i have used ldr sensor to detact light .

1 coin batter and also a switch so that you can off 

it when putting in packet in daytime to save battery .

# Pcb

the pcb is made in kicad .

 [![View PCB on KiCanvas](https://hack.club/pcb-badge)](https://kicanvas.org/?repo=https://github.com/ayush-bug/f-22_raptor_keychain_pcb/tree/main/PCB)

# BOM

 Bill of Materials

- 5 x custom pcb 
- 5 x BC547 NPN DIP Transistor
- 5 x 100k resistor
- 5 x 220 resistor
- 5 x keychain rings and hooks
- 5 x CR2032 coin cell
- 5 x CR2032 smd coin cell holder
- 5 x 3mm led
- 5 x 5mm LDR Sensor
- 5 x Slide Switch SS-12D00 1P2T
